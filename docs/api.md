# Использованные API SillyTavern

Проверены непосредственно в checkout `release` **1.19.0**, SHA `06bde939fb1e9c4c8d8641d810f0a916b5bce127`. Никакой автогенерации/перехвата групп в RPG Core нет.

- [`SillyTavern.getContext()`](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/st-context.js#L115-L170): chatId, groupId, characterId, characters, chatMetadata, extensionSettings, eventSource, eventTypes, setExtensionPrompt, saveMetadata, saveSettingsDebounced.
- [`setExtensionPrompt(key,value,position,depth,scan,role,filter)`](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/script.js#L8915-L8938): собственный ключ `rpg-core-state-v1`, IN_CHAT=1, depth=0, scan=false, SYSTEM=0. [Enum definitions](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/script.js#L484-L499). Инъекция обновляется при загрузке чата, изменении данных и GENERATION_AFTER_COMMANDS; очищается на disable и при отсутствии валидного состояния.
- [`saveMetadata()` → saveChatConditional](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/script.js#L9408-L9440): исключения могут перехватываться внутри ST. [Групповой header сериализует metadata](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/group-chats.js#L623-L652).
- [`events.js`](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/events.js#L1-L65): используются APP_READY, CHAT_CHANGED, GENERATION_AFTER_COMMANDS, MESSAGE_SWIPED, MESSAGE_DELETED, GENERATION_STOPPED, GENERATION_ENDED. Только CHAT_CHANGED загружает state; generation events не применяют transitions.
- [`EventEmitter.on/removeListener/emit`](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/lib/eventemitter.js#L31-L158): обработчики ожидаются; APP_READY auto-fire позволяет позднюю загрузку. Ни один обработчик RPG Core не вызывает generate/trigger.
- [`manifest` compatibility и hooks](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/extensions.js#L406-L493), [minimum_client_version](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/extensions.js#L575-L638): enable/disable — экспортируемые функции entry module. Disable удаляет listeners, HUD и injection; pending save не возвращает HUD.

Все отложенные операции проверяют актуальный чат/epoch. Это не доказательство корректности всех будущих ST версий. Upstream уже предупреждает о mutable context: реальные hosted-версии требуют smoke-проверки.
